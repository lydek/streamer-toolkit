# 範圍

## 定位
本機優先的 Twitch 實況互動工具，只做實際直播用得到的功能。目標是取代目前依賴的第三方聊天室、特效與 SO 服務。

## 責任邊界
- Twitch 管頻道點數的餘額、扣點與退款；本工具只接收兌換事件、存紀錄、觸發本機動作。
- 本機兌換紀錄可能因離線或漏接而不完整，不宣稱與 Twitch 完全一致。
- Twitch、OBS 仍是必要的外部服務；「本機優先」不等於完全離線。
- SO 播放的影片仍來自 Twitch，來源失效時無法播放。

## MVP 功能切片
依序做，每片做完就實際直播試用，沒問題才做下一片。順序可以依直播需要調整。

| # | 切片 | 完成時看得到什麼 |
|---|---|---|
| 0 | Walking skeleton | 首次設定引導註冊 Twitch app 並填入 Client ID，用 Device Code Flow 登入，Token 存 keyring 並自動刷新；Tauri 視窗啟動本機 Host（port 被佔用時提示並可修改）；OBS Browser Source 載入本機網址並顯示 Twitch 聊天；[decisions.md](decisions.md) 標為「Skeleton 就建立」的基礎都已就位 |
| 1 | 自訂聊天室 | 改 HTML／CSS 樣板後 OBS 立即套用；斷線時畫面顯示狀態並自動重連；管理 UI 顯示 Twitch 與 OBS（OBS WebSocket）連線狀態 |
| 2 | 追隨／訂閱特效 | 事件觸發 Overlay 動畫與音效；可用事件模擬器測試，不用等真的有人追隨 |
| 3 | 兌換紀錄 | 收到頻道點數兌換就存檔（依兌換 ID 去重），UI 可查詢；第一個複雜模組 |
| 4 | 打卡簽到 | 觀眾可用頻道點數兌換、聊天室指令打卡，實況主可在 UI 手動登記或補登；同一觀眾同一營運日只算一次，依實況主設定的時區切日；可匯入舊打卡資料（匯入前預覽、去重、不破壞原檔；支援格式待確認） |
| 5 | 音效管理 | 匯入本機音效檔，指定由哪個事件觸發 |
| 6 | 備份還原 | 一鍵匯出／匯入設定與紀錄，匯入後資料完整 |
| 7 | Windows 安裝檔 | 另一台電腦可安裝並使用；安裝檔附第三方授權清單 |

**MVP 之後（已確認需求）：** 個人徽章、SO 剪輯。技術面的後續項目見 [decisions.md](decisions.md)。

**其他想法：** 記在 backlog，不排程，不寫規格。

## 不在這次範圍
抽獎、點歌。

## 不做
通用規則引擎、Linux、原生手機 App、雲端服務。

## 加新功能前問三題
1. 它解決我直播時已經遇到的問題嗎？
2. 最小做到哪裡就能拿去直播用？
3. 它會拖慢目前正在做的切片嗎？
