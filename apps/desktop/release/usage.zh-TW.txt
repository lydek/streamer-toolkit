Streamer Toolkit 使用說明

【第一次使用】
1. 在下載的 zip 上按右鍵，選「內容」，勾選下方的「解除封鎖」再按「確定」（沒有這個選項就略過）。
   沒有先解除封鎖，解壓縮出來的檔案都會被 Windows 當成來自網路。
2. 在 zip 上按右鍵，選「全部解壓縮」，目的地選自己可以寫入的位置（例如「文件」），
   不要放在「Program Files」。解壓縮後會得到「Streamer Toolkit」資料夾。
3. 開啟資料夾裡的「Streamer Toolkit.exe」。
4. 如果出現「Windows 已保護您的電腦」（SmartScreen），按「其他資訊」，再按「仍要執行」。
   程式沒有數位簽章，所以會出現這個提示。

設定與紀錄都存在同一個資料夾裡的「data」資料夾。

【更新】
1. 先結束程式：在系統匣的圖示上按右鍵，選「結束」。
2. 新版的 zip 一樣先「解除封鎖」。
3. 「全部解壓縮」預設會再建立一個新資料夾。請把目的地改成舊的「Streamer Toolkit」資料夾
   所在的那一層（例如舊資料夾是「文件\Streamer Toolkit」，目的地就選「文件」），
   出現檔案已存在的提示時，選「取代目的地中的檔案」。
   解壓縮到其他地方的話，新版會從空白的設定開始，原本的設定與紀錄還留在舊資料夾裡。
4. 開啟「Streamer Toolkit.exe」。zip 裡沒有「data」資料夾，取代時不會動到設定與紀錄。

【需要】
- Windows 10 或 Windows 11（64 位元）。
- Microsoft Edge WebView2 Runtime：Windows 11 內建；缺少時程式會說明並開啟下載頁。
